# Gallery: further application domains

Compact, runnable examples beyond the article's Section 3. All masses are
synthetic and illustrative, not validated domain models.

| Script | Shows |
|---|---|
| `loading_masses_from_csv.py` | Integration path with external data: `MassFunction.from_csv()` on the article's pump sources |
| `medical_diagnosis.py` | MYCIN-style expert system on a classical DST frame |
| `target_recognition.py` | High-conflict sensor fusion: Dempster vs PCR5 |

Run with `uv run python examples/gallery/<script>.py` (no extra dependencies).
